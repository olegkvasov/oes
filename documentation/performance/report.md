# Производительность — замеры ожидают запуска

Runner реализован в `tests/performance/run.ts`: 1000 машин, прогрев 30 секунд, затем 10 минут наблюдения. Измеряются завершённые отрисовки Canvas, long tasks по минутам и JS heap после сборки мусора. Отчёт заменяется фактическими результатами при успешном запуске.

Запуск: `make perf`. Длительная проверка: `PERF_MINUTES=720 make perf`.

Результаты пока отсутствуют: среда агента запрещает открывать локальный порт (EPERM). FPS ≥30, long tasks ≤1/мин и рост heap ≤10% не подтверждены. Этот файл не является положительным результатом проверки.
