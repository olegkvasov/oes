# Диспетчерская

Рабочая заготовка реализации Tasks.md: Vue 3 + TypeScript, Canvas, Node/Fastify/WebSocket.

## Запуск

Node.js 24 и Yarn 1.22.22 (версия закреплена в packageManager). Установить зависимости: `yarn install`.
В двух терминалах: `make mock` и `make dev`. Открыть URL Vite (обычно http://127.0.0.1:5173).
`LOAD=1000 FAULTS=drop,dup,reorder make mock` включает нагрузку и отказы. Другие флаги — Tasks.md.
`make check` — типы, ESLint, базовые AST-проверки архитектуры и Prettier; `make test` — модульные тесты; `make build` — сборка.

## Текущее состояние

Добавлены сервер, экран, снимок/seq/reset, серверное время, роли, идемпотентные команды и сообщения о конфликтах. Экран показывает серверные значения; reason выводится как текст.

## Проверки

`make test` — 32 теста: поток, версии, замена снимка, время, устаревание, валидация, HTTP-команды через Fastify inject и намеренные нарушения архитектуры.
`make e2e` — последовательные запуски Playwright с normal, drop/dup/reorder (5 минут), reset, slow, stale и observer. Потребуются свободные порты 3001/5173 и установленный браузер (`yarn playwright install chromium`). Сценарии приостанавливают симуляцию через тестовый endpoint и сравнивают все машины, пункты, очереди, решения и seq с сервером, дополнительно проверяют DOM и цвет устаревших машин на Canvas. TEST_CONTROL=1 и VITE_E2E=1 устанавливаются только E2E-конфигурацией.
`make perf` — самостоятельно запускает заглушку с LOAD=1000 и Vite, прогревает страницу 30 секунд, измеряет 10 минут и пишет `documentation/performance/report.md`. Выходит с ошибкой при превышении порогов. До запуска остановить ручные серверы на тех же портах. Для проверки 12 часов: `PERF_MINUTES=720 make perf`. FPS измеряется непосредственно в отрисовке Canvas.

Проверены: типы, базовые архитектурные проверки, 32 модульных/интеграционных тестов и production-сборка. Попытка запуска Playwright остановлена средой до тестов: EPERM при открытии 127.0.0.1:3001. Браузерные сценарии, визуальное качество и численные показатели производительности не подтверждены.

## Оставшиеся ограничения

Нет полного покрытия архитектурных ограничений: AST-проверка контролирует статические и строковые динамические импорты, namespace-доступ к клиенту, циклы файлов и модулей, транзитивные зависимости компонентов от API и размещение функций. Смысловое различие бизнес- и технических функций требует ревью; произвольную динамическую генерацию кода анализатор не доказывает. Отдельный 12-часовой прогон не выполнен. Кеш ответов идемпотентности сервера пока хранится до перезапуска, без удаления; ограничивать его без согласованного срока гарантии повторов нельзя. Лента показывает 100 последних решений, внутреннее состояние ограничено последним часом.

## ESLint и Prettier

Конфигурация ESLint включает рекомендуемые правила JavaScript, TypeScript и Vue 3. Конфликты форматирования отключены через eslint-config-prettier. Prettier: одинарные кавычки, отступ 2 пробела, ширина 100, точки с запятой.

После добавления этих инструментов выполнить `yarn install`, затем `yarn format` и `make check`. `yarn lint:fix` исправляет автоматически исправимые замечания ESLint; `yarn format:check` проверяет формат без изменения файлов. `make check` включает обе проверки.

Используется Yarn Classic 1.22.22 и единственный lock-файл `yarn.lock`. Для воспроизводимой установки на чистом клоне: `yarn install --frozen-lockfile`. При изменении зависимостей используйте `yarn add` / `yarn add -D`, сохраняйте обновлённый `yarn.lock`.

Yarn принимает перенесённый lock-файл на этапе разрешения зависимостей. Чистая установка не проверена: скачивание архивов недоступно в среде агента. Команды проверяются на уже установленных зависимостях. Для запуска скрипта check напрямую используйте `yarn run check`: `yarn check` — встроенная команда Yarn Classic.

## Структура репозитория

Документы находятся в `documentation/`, включая этот README, задание, архитектуру, план и правила агента. Корневые README.md и AGENTS.md содержат только навигацию.

Тесты: `tests/unit/` — Vitest, `tests/e2e/` — Playwright и runner сценариев, `tests/performance/` — нагрузочный runner. Конфигурации тестов лежат в `tests/`; команды `make test`, `make e2e` и `make perf` остаются прежними. Прямой запуск Playwright: `yarn playwright test --config tests/playwright.config.ts`. Артефакты браузерных проверок находятся в `tests/.artifacts/`, итоговый отчёт производительности — в `documentation/performance/report.md`.

`make check` проверяет размещение файлов через `scripts/check-layout.mjs`: новые документы вне documentation и тесты вне tests запрещены.
